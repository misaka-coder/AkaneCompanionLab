# 五子棋同伴插件（akane.gomoku）

基于 Akane Plugin SDK 的 15×15 五子棋盘和启发式战术评估。

模型工具：

- get_game_state：当前盘面、轮次、执子方和版本。
- analyze_board：威胁、进攻机会和防守建议。
- suggest_moves：候选走法。
- place_piece：伴侣实际落白子，并返回成功或拒绝原因。

桌面程序服务 board.v1.control 提供玩家落子、读盘、悔棋、重开和本地人机操作。该服务不加入模型工具目录。玩家与模型共用同一盘面，按用户、会话、角色和对局 ID 隔离；写操作检查轮次、版本与合法坐标。盘面存在插件内存中，后端重启后不保留。

插件声明的权限仅为模型工具贡献和程序服务贡献，不需要发消息、请求 Agent 回合或操作桌面。唤醒模型由现有桌宠聊天入口处理。

安装可使用设置页的本地源码安装，选中本目录，查看并确认声明的权限。宿主将构建、检查并启用插件。详细调用链和验证方式见 docs/gomoku_companion_game_v1.md。
