# 控制中心桥接层拆分

生产入口仍是 `control-center-lab.html` → `control-center-v2/index.js` → `bridge.js`。
`bridge.js` 从 676 行缩为 8 行，保留 `createControlCenterBridge` 与 `shouldUseInstanceAdminProxy` 两个公开导出。
界面仍通过 bridge、既有 action router 和 data source 操作后端与宿主。

## 修复的行为

- 聊天成功、空结果和异常都先验证发起请求的范围。同名会话不会跨 bot、角色、用户或后端合并；切出去再切回也不会恢复第一次的旧请求。
- 切换范围立即清除旧聊天数据和分页游标，并显示“正在切换会话”。成功读取后恢复当前会话；失败保留实际原因。
- 聊天尾部与分页锁归属于当前范围。旧分页结束不会释放新分页锁；新会话可以直接读取，无需等待旧会话。
- 必需快照有独立刷新锁。聊天尾部的慢请求不会占住它；旧快照、模型结果及插件目录不会进入新绑定或已关闭窗口。
- 三类插件读取共用发布规则，分别保留 loading、available、unavailable 和错误原因，慢插件市场不阻塞主快照。
- 重复启动先清理旧订阅与设备轮询。关闭过程中尚未注册完成的监听器，在返回后立即取消；旧注册失败不会清理新窗口的监听器。
- 关闭立即取消附件、音频等长时间确认。迟到的附件序列化不能向新角色发出操作，旧操作也不能再次触发刷新。
- bot 切换仍须匹配自己的操作回执，再校验当前运行状态和持久绑定；迟到的初始化不能覆盖新的选择。
- 新订阅者只收到自己的缓存状态，避免重复通知已有订阅者。

实例绑定检查、原 admin 代理方法/路径规则和操作确认超时保留。密钥仍由原宿主代理处理，未增加浏览器密钥存储。
分页仍通过既有 `/sessions/messages` 游标接口完成。
观察操作集合与超时已收敛由 `settings-command-contract.js` 统一产生；空闲停止在收到匹配的成功回执且快照已停止时即可确认，不再强制要求操作前出现运行到停止的状态跃迁。
