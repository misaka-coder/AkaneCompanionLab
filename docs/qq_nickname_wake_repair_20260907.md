# QQ 昵称唤醒 repair pass — 2026-09-07

## 生效规则

- Bot 配置省略 `wake_words` 或给出空数组时，跟随绑定账号的 QQ 登录昵称。
- 非空 `wake_words` 仍是显式覆盖；沿用最多 8 个词、每词最多 32 字符的校验。
- 不再从实例适配器、Bot 显示名、角色名或协议包隐式补入 `Akane`。
- 昵称只取自绑定 OneBot 的 `get_login_info`，返回账号必须匹配配置账号；不信任入站 @ 的显示文字。
- 缓存成功结果 60 秒；刷新失败立即停用旧昵称，15 秒后可重试。失败或非法昵称时，明确 @ 和私聊仍可用；自检返回 `wake_word_mode/status/words`。
- 这里只跟随账号昵称，不读取群名片；角色切换不擅自修改 QQ 昵称。多个机器人若实际使用同一昵称，无 @ 的文字唤醒仍可能同时触发，应使用不同昵称或显式别名。
- 只 @其他人（含 @全体）时，正文中的唤醒词不抢占接收对象；多人 @包含自己仍正常唤醒。
- 有序消息投影中的 @自己使用验证过的 QQ 昵称；查询失败使用中性“助手”，不固定渲染成 Akane。历史消息不重写。

## 权威边界

`channelcore-onebot` 的 `inbound.py` 统一拥有空唤醒词及显式接收对象优先规则。
Akane 网关只负责昵称查询/缓存、产品配置和投影标签，没有增加第二套 OneBot 解析器。
包的原有未提交改动在操作前与已安装 Python 包逐文件比对相同；本轮仅增加独立 inbound 修复、测试和说明，未夹带提交既有引用/转发改动。
