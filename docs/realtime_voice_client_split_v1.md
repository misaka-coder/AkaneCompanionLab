# 桌宠实时语音客户端拆分记录

## 范围

原 `desktop_pet_next/src/realtime-voice-client.js` 为 2,035 行。按播放、采集资源、单轮会话、持续通话及协议/PCM 工具分片迁移；保留原路径和八个公开导出，桌宠仍通过现有认证桥接访问后端。

生命周期、音频所有权、JSON 头与二进制帧顺序以及客户端实际播放回执仍在真实调用链中验证。当前用户的未跟踪 `tools/` 不属于本轮。

## 第一片：播放队列

- `src/realtime-voice/playback.js` 提供原 `RealtimeVoicePlaybackQueue`，包含音量控制、播放控制回执、音频对象 URL 和事件清理。
- 根入口导出同一类对象，会话和共享资源直接使用该实现。
- 新增行为测试先复现：停止旧音频后，它已排队的 `ended` 或 `error` 回调会错误结束继任音频。事件回调现在确认所属音频仍是当前项，防止迟到回执归到新音频。
- 慢 `play()` 在打断后完成，继续由既有项身份检查阻止旧音频的播放成功回执。

3 项新增回归测试、原实时语音 smoke 和前端构建通过。AST 对照保留原有 107 个函数/方法的签名，函数体仅有 `RealtimeVoicePlaybackQueue.playNext` 的所属项检查差异。

## 第二片：采集资源与协议基础

- `capture-resources.js` 保存整通电话的麦克风租约、闲置预录和共享播放器归属；`protocol.js` 保存协议版本、超时和端点/平台检查，避免跨文件复制常量。
- 共享采集在启动前及异步恢复后检查关闭状态，关闭后不再接受 PCM；单轮独立采集在模块加载和恢复后检查当前上下文，初始化失败及时释放节点及上下文。
- 新增关闭期间模块加载/恢复、关闭后重新启动、迟到 PCM 检查。6 项中 5 项先在原实现失败，修复后连同播放测试共 9 项通过。

原实时语音 smoke 和前端构建通过；AST 对照继续保留原有 107 个签名。此片仅调整共享采集的启动/事件守卫和单轮初始化失败清理。

## 第三片：两种会话与 PCM 工具

- `single-session.js` 保存单轮状态和协议接收；`call-session.js` 保存整通电话的连接与跨轮路由；`call-turn.js` 保存每轮输入和响应状态。仍使用同一实例及已有音频归属机制。
- `pcm.js` 收敛两种输入重复的 PCM 回退缓存、丢帧判断、释放和 WAV 编码；保留原对象字段及公开方法。缓存不完整时继续返回不可回退，不把截断语音当作完整输入。
- 原入口仅提供八个静态兼容导出；新增导出身份和依赖方向检查，防止实现重新堆回入口。

新增行为测试先复现、再修正会话收尾问题：关闭后的消息及异步 Blob 结果不再创建播放或触发展示；解码失败产生明确的终止失败；服务端通话关闭与本地挂断共用清理，结束等待、释放轮次、清除超时；已取消的轮次在每个异步采集边界验证当前归属，不再向服务端发送旧输入开始。单轮重复初始化的清理只释放其自己的旧上下文，保护继任采集。

## 基线与最终验证

拆分前运行了实时语音、端点、通话流、打断、麦克风取消、桌宠会话、TTS 展示及会话认证共 8 组 smoke；7 组通过。打断 smoke 在旧 `activity` 动作渲染断言处失败；仓库 `owner_private_memory_unification_plan_v1.md` 已明确移除该回复副作用，生产代码没有该调用。收尾更新这项 smoke，明确回复元数据不执行旧动作，继续验证当前播放的情绪展示、旧轮隔离和重复终态；未改动 `pet/voice.js` 的生产行为。

最终验证：

- `npm run test:realtime-voice`：24 项通过，覆盖上述异步边界、WAV 样本、缓存完整性、八个公开导出身份和静态依赖。
- 原 8 组语音 smoke 全部通过。
- `check:pet-runtime` 检查 29 个主窗口模块的接口、状态归属、导入边界、语法及名称；`smoke:pet-runtime` 的启动/重进、流式回复/取消、对象切换、媒体、麦克风取消及清理全部通过。
- `smoke:pet-browser` 使用 Edge 的真实主窗口入口及 DOM，验证资源、输入、流式回复、失败、慢请求/会话切换和重进；0 项页面错误。HTTP 为受控返回，未连接实际后端。
- 前端 `npm run build`、相关 11 个文件 `node --check` 和 `git diff --check` 通过。
- AST 对照保留原有 107 个函数/方法的参数、默认值、异步标记和方法类型；函数体差异均为上述生命周期修复与 PCM 重复实现收敛。

实际麦克风、WebView2 播放器和远端 ASR/TTS 尚需现场验收。本轮浏览器检查验证主窗口装配与交互，音频时序通过生产类及受控设备/传输端口验证。
