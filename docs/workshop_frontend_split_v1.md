# 角色工坊前端拆分 v1

起始文件 `desktop_pet_next/src/workshop.js` 为 4,204 行。本轮仅处理前端，
保持角色包的 Tauri 文件操作和后端请求契约，后端由用户继续调整。
已有后端、技能、私有记忆规划、其他测试与 `tools/` 改动保留。

## 基线与切片一

拆分前 48 项前端和实例契约通过；角色工坊浏览器行为 smoke 通过，覆盖
校准几何与目标归属、设定草稿、隔离测试请求、立绘变更、刷新和写入竞争、
弹窗归属、导入导出与移除角色后的空态，页面错误为 0。Vite build 通过。

第一片提取常量、公共值处理、角色包模型、立绘能力模型、校准值模型、
测试对话模型、DOM 构建、文件选择和后端桥接，共 9 个模块。
入口降为 3,659 行；身份核验缓存仍属于当前工坊实例。模型和传输函数体
保留，移除静态符号引用确认未使用的 `shortId`。

源契约测试沿实际入口导入读取工坊实现，保留原断言；浏览器 fixture 只替换
原生接口导入，保留新模块导入。新增模块检查验证依赖无环、实现不反向导入
入口及未绑定名称，新增 `smoke:workshop-modules` 和 `smoke:workshop-browser`
复验命令。浏览器 smoke 支持通过 `AKANE_PLAYWRIGHT_MODULE` 选择已有的
Playwright 安装，本轮使用工作区依赖运行，未增加运行时依赖。

切片一验证：9 个模块检查、48 项契约、全部既有浏览器行为检查及 Vite build
通过。提交前检查 diff 和暂存清单，仅提交本轮工坊、验证脚本、相关测试及
此说明。真实角色包写入、外部抠图服务与真实桌面交互不由 fixture 代替验收。

## 切片四：启动、页面组装与事件接线

前一切片提交：`7eadf4f1`。

`workshop.js` 最终为 16 行，只接入原生接口、样式与应用启动；
`workshop/application.js` 为 226 行，显式组装控制器、当前窗口状态与原有
启动和页面退出流程。页面元素查询、事件绑定、标签导航与渲染各自独立。
已初始化的方法直接传递；需要后续控制器的方法保留延迟回调，避免初始化
顺序导致未就绪的访问。原有空段落注释及入口未使用的导入一并移除。
