## 用户可见变化

```json
{"action":"get_mini_app_ark","params":{"source":"BV1GJ411x7h7"}}
```

宿主查询 B 站真实视频元数据，取得标题、封面和数字 aid，交给 NapCat 原有模板/签名接口。支持 BV 号、普通视频页与 b23.tv 短链；不下载视频，不读取账号 Cookie，不处理直播、合集或指定分 P。

正常生成只返回 `stage=generated`、`card_ref`、标题、网页地址和有效期，不再把整段签名 JSON 交给模型复制。发送仍使用既有 `send_group_msg` / `send_private_msg`，传 `card_ref` 即可；不能同时传 `message`。普通文本和已有消息段发送不受影响。

微博与手工自定义生成仍保留，正常生成统一进入同一套句柄发送链；原始 Ark 模式仅供按需读取，不宣称可发送。已存在的卡片仍使用既有原消息转发能力，没有再造转发或签名实现。

## 安全及失败语义

- B 站抓取复用原有公网 URL / DNS / IP 固定连接与响应 peer 校验，每一跳先检查站点白名单；短链最多 3 次跳转，正文上限 512 KiB。禁止内网、外站跳转、携带凭据的 URL 及 HTTPS 降级。
- 元数据需核对请求的视频身份、标题、真实封面 CDN 和数字 aid。412/403/429、超时、缺项、失效、畸形响应均返回结构化错误，不编造材料或自动改成普通链接。
- 卡片缓存归属于单个 Bot，并绑定操作者、会话和角色。容量 128，15 分钟或进程重启失效；不落库、不迁移历史。
- 一个句柄只尝试发送一次，含超时和结果不确定的情况。并发重复调用不会再发送；完成后的重复调用返回前次实际回执并标记 `duplicate_suppressed`。未知或已过期的句柄不会重放。
- 发送复用原有权限、消息回执、插件 Hook 和交付记录调用链。生成成功不表示已发送；发送回执也不等于客户端外观/点击通过验收。
