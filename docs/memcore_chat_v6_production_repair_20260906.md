## 数据处理边界

- 在停机一致性备份后使用现有 V6 显式迁移入口重建派生聊天投影。
- 仅隔离 `master / cecilia / master` 私聊中已确认带错误时间戳的两个助手
  final；所有原始正文和 provider 原文保留，未改写为伪造 JSON。
- 隔离同时移除这两个 final 的派生投影并失效对应 settlement，避免隐藏
  条目后仍读取旧冻结投影，或触发 `projection_entries_stale`。
- 两条目标没有进入阶段摘要，也没有关联派生摘要，不清空正常摘要、长期
  记忆、用户消息或整段会话。
- 隔离后不进入正常 prompt、检索索引或未来语义压缩。备份可恢复。

演练暴露并修正了“先隐藏后迁移”的维护顺序错误；正式流程先迁移，再原子
隔离条目与派生缓存。首次启动还因新环境目录权限失败而触发保护回退；修正
权限后使用服务账户重新通过门禁，并在新的停机备份后重新执行修复。
