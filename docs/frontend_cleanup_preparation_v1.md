## 本阶段范围

1. 删除旧 Electron 的 44 个版本控制文件和专属启动脚本。新桌宠统一从 `desktop_pet_next/` 开发。
2. 删除旧 Web 聊天、Monogatari 包装页、资源预览、Live2D 预览、其模块与 vendor 脚本；删除相应静态路由及预览启动器。
3. 启动模式从 `Auto / Desktop / Web` 收敛为 `Auto / Desktop / Backend`。默认仍启动 Tauri；`-Mode Backend` 仅运行后端并检查健康，不开网页。不存在旧 Web 自动降级。
4. 清除创建新桌宠对话的完整前端链路。角色首次初始化、切换 Bot/角色、后端返回规范会话 ID 时仍使用原有会话归属逻辑；不迁移或删除历史记忆。
5. 同步当前协作约定、开发入口、项目地图、中英文 README 和启动检查。历史设计文档保留为历史记录，不能据此恢复旧客户端。
6. 删除只针对退役客户端的源码断言。现行桌宠取消、慢请求、切换归属与重新进入的检查使用现行调用链。

保留 `web/assets/`：后端资源清单、商店图标、场景和部分 QQ 资源仍引用这里。目录名暂不迁移，避免本次清理扩大为资源协议迁移。旧 `desktop_pet` 的本地忽略依赖可能仍占磁盘，但已不属于源码与启动流程。

模型使用的 Chrome/浏览器自动化、PC Use、桌面 WebView2、Vite 开发与浏览器 smoke 都是现行能力，不属于退役 Web 客户端。片刻小屋 `scene.html` 也保留。

设置页只有 `control-center-lab.html` 一份实现；`settings.html` 和 `control-center-v2.html` 仅跳转。保留这两个轻量兼容文件，窗口命令与旧书签不会意外指向另一套界面。

## 下一阶段准备

先按“聊天、日常控制、配置、作者编辑”整理入口，再决定布局与视觉。不要先套新皮肤把原来的所有卡片重新堆一遍。

- 右键面板：优先聊天、停止任务、声音、设置；文件、音乐、游戏入口按实际使用频率安排。
- 完整设置：模型、声音、角色外观、能力、系统分别有清楚归属；状态、编辑与高级诊断避免同屏混排。
- 文件：区分本轮附件、收到的生成物和保存的文件；不要要求用户理解内部 workspace/session/job 标识。
- 角色：普通用户选择和切换角色，作者创建/编辑角色。编辑功能无需全部挤在日常外观页。
- 插件：管理现有插件与寻找/安装插件分开；技术依赖说明在失败或详情时出现，安装暂存仅在安装流程里出现。

这些是后续设计输入，当前没有实施整页重新布局，也没有新增 UI 框架。

## 2026-10-13：死代码复查

从当前 HTML 入口跟踪静态导入、动态导入及 worklet，再核对生产代码、测试、原生窗口与当前文档的引用。测试单独调用的函数不能据此当作生产功能；Vue 模板使用的函数和动态加载的 Pixi 渲染器不属于死代码。

本轮确认并删除：

- `src/control-center/action-helpers.js`：旧设置页的 dataset 转换和时间标签解析器，现行设置页由 `control-center-v2/app/events.js` 与页面控制器处理事件，没有生产调用。
- `src/control-center-lab.js`：无人导入的 JavaScript 兼容适配器。主 HTML 已直接加载 V2；两个 HTML 跳转仍保留。同步验证清单、源码断言与项目地图。
- 角色模块中闲置的身份、文本、资源快捷常量和五个 getter，以及重复的 `getProfileText`。角色包字段本身与现行动态读取路径保留。
- `resetCareEvaluationBaseline`：后端成为养成状态权威后，前端不再重置计时基线。删除只针对该旧函数的测试，保留后端权威、开关和快照检查。
- `buildDroppedAudioItems` 及其专属歌词后缀、路径检查、文件名匹配函数：实际拖入已走统一 workspace 导入链。保留当前音乐格式集合、歌词解析、队列和工作台音乐逻辑。
- 无调用的实例 ID getter、五子棋棋谱反向解析器；保留实例隔离和棋盘坐标输出的行为检查。
- 退役 Web 专用 `/app-config` 路由，以及 `WEB_IDENTITY_MODE` 设置、归一化函数和目录条目。旧配置键通过现有退役键诊断报告，不再生成一个没有作用的设置项。

`WEB_OWNER_PROFILE_USER_ID` 仍被 QQ 语音、搜索和能力权限使用，因此沿用其配置键名；设置分类改为“主人身份”，说明实际用途。根 `.gitignore` 补充 `node_modules/`，避免旧客户端 `.gitignore` 移除后，本地依赖被误当作待提交源码。
