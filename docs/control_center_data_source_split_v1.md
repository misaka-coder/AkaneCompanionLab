# 控制中心数据源拆分 v1

起始文件 `desktop_pet_next/src/control-center/data-sources.js` 为 3,769 行。
本轮只处理前端，后端由用户继续调整；原有技能、说明和 `tools/` 改动保留。
目标是明确数据读取、领域动作、桌面桥接和状态投影边界，保留六个公共导出、
动作 ID、Bot/用户/会话/角色作用域和异步选择保护，按可回滚切片提交。

## 基线与切片一

拆分前控制中心验证矩阵通过：91 个生产动作、28 个事件、9 个 invoke、14 个
后端路由，以及 V2、统一快照/旧端点回退、聊天历史、不可用状态和私有路径
投影的行为 smoke。前端契约 42 项通过，Vite build 通过。原 UX smoke 的
截图阶段因为 Puppeteer 不可用跳过；最终另做浏览器检查。

第一切片将公共值处理、HTTP、目录读取、快照形状，以及概览、角色、声音、
音乐、能力、审批、服务商、MCP、工作流和指标投影移入 `data-source/`。
入口降到 1,777 行。原声明体保持，移除静态引用分析确认未使用的
`tauriInvokeOnlyActionIds` 和 `pickBoolean`。请求和验证状态仍由数据源实例持有。

源代码契约测试改为沿入口的实际导入读取实现；新增模块 smoke 校验依赖
无环、实现不反向引用入口和六个公共导出，并接入既有控制中心验证入口。

第一切片验证：动作桥、V2 和运行时 smoke 通过；16 个可达模块的依赖检查、
42 项前端契约、Vite build 与 diff 检查通过。

## 切片三：实例组装、读取与失败状态

前一切片提交：`85e3c5ce`。

公共入口现在为 5 行导出，实例组装 `data-source/source.js` 为 96 行。
31 个实现模块全部可从入口到达，最大模块为 382 行；六个公共导出，以及
数据源实例的 28 个属性、方法参数数量、属性描述和初始状态与拆分前一致。

| 模块边界 | 职责 |
| --- | --- |
| `source.js`、`health.js` | 选项归一化、实例组装、身份核验、健康缓存与核验中的请求 |
| `readers/` | 快照与旧端点回退、会话与历史、目录、工具曝光读取及保存 |
| `actions/` | 设置写入、领域动作、桌面/后端动作选择及通用动作结果处理 |
| `tauri.js` | 原有窗口、设置事件、角色声线和本地路径桥接 |
| `projections/` | 后端与桌宠状态到界面状态的转换，不发起请求 |
| `shared.js`、`http.js`、`catalog-reads.js`、`snapshot-shape.js` | 公共值处理、传输、目录补充读取与快照契约 |

健康缓存、核验中的请求、回退原因和聊天错误仍属于各自数据源实例。
各方法工厂显式接收所需上下文；模块 smoke 除依赖无环、实现不反向导入
入口及公共导出外，还检查未绑定名称，防止拆分遗漏闭包上下文。
统一快照与旧端点回退保留各自的 URL 和策略语义。

四项新增失败回归在修复前均能复现；本片处理了以下问题和冗余：

- 通用动作的空、畸形或未声明 `ok` 的响应返回 `invalid-response`，不再报执行成功；声明失败但缺少状态时使用 `failed`，保留已有失败原因。
- 设置保存遇到 HTTP 失败且响应体声称成功时，保留 HTTP 失败状态。
- 较早的聊天读取失败不能覆盖后来请求的会话错误状态；调用方仍获得各自读取结果。
- 声线保存与试音共用参数字段映射，保留各自专有参数及 `false`、`0` 的传输值；音量和时间值处理移入公共层。

最后一项行为检查验证保存与试音的实际请求体，共 5 项新增行为测试通过。
完整控制中心验证矩阵通过，包含模块与状态检查、91 个生产动作、V2、
运行时 probe、Vite build 和 UX 构建产物检查。Bot 路由、工具曝光、QQ 设置、
聊天文件行为 smoke，以及 42 项前端契约通过。

浏览器使用指定离线后端地址，检查 7 个功能页切换、聊天页重新进入、
刷新和页面重载；不可用提示与禁用状态正常，未捕获脚本错误。
原 UX smoke 的 Puppeteer 截图仍跳过，本轮浏览器验收通过内置浏览器完成。
真实 Tauri 窗口、音频播放和外部服务尚未在本轮验证。
