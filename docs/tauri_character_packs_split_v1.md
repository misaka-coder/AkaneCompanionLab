# Tauri 角色包与立绘拆分

本文件记录角色包拆分阶段的结果。后续主入口已从 6161 行收敛到 128 行，角色激活迁入 `pet_state/persistence.rs`，角色常量迁入 `character_packs/constants.rs`；当前模块定位与最终验证见 [Tauri 主入口拆分收尾](tauri_main_split_v2.md)。

## 范围与边界

- 入口：`desktop_pet_next/src-tauri/src/main.rs`，原始 8383 行。
- 完成后入口 6161 行，角色包与立绘分为 16 个生产模块，最长 283 行；测试及临时目录夹具独立于生产模块。
- 角色工坊继续通过现有 Tauri 命令读写角色包，命令参数和序列化字段保持兼容。
- 角色激活涉及桌宠状态与窗口存在性，仍由入口的 `activate_character_pack` 管理。
- 系统媒体、桌面连接、工作区交付和窗口控制不在本轮拆分范围。
- 文件测试使用独立临时目录，不修改真实角色目录或进程的数据根配置。

## 行为修复与验证

- `plugin-followup-smoke.mjs` 读取当前生产函数，移除对已删除 `applyPayloadActivity` 的引用及未使用的源码变量。真实插件生成文件到桌宠交付链路的 9 项测试通过。
- 原先所有写入共用 `.{name}.tmp`，会覆盖别的写入者，并在失败时残留临时文件。现使用 `create_new` 独占创建临时文件，写完并关闭后替换，失败时只回收自己创建的文件。
- 旧格式立绘只在新文件替换成功后清理。4 项 Rust 文件行为测试覆盖并发写入、已有临时文件、替换失败和成功清理。
- 模块迁移后，27 项 `DesktopPetFrontendContractTests` 通过。结构检查通过入口实际声明的模块查找实现，不依赖大文件的旧行号。
- 角色列表、身份编辑、声线编辑、资料库登记及新建角色复用同一结果投影和资源根默认规则。
- 保存设定只更新内容仍等于旧自动模板的 `persona.md`，保留手工编辑过的文本，即使其中保留了模板标题。读取错误保留原因，不把读取失败当作文件不存在。
- 资料库在清洗文件夹名称前拒绝 `_local` 保留名，避免它被去掉下划线后误当成普通名称。6 项配置行为测试覆盖手工文本、模板更新/缺失、字段保留、无效编辑、无效创建及资料库重复/保留名。
- 复用已有 `zip` 依赖读取 Stored 和 Deflate，解决桌宠自己导出的压缩 ZIP 无法重新导入的问题。保留目录标记，按确切文件名识别 `character.json`，检查 CRC、归一化重名及压缩前后大小上限。手工 ZIP 中央目录读取代码已移除。
- 每次导入独占暂存目录，覆盖前先校验，发布失败时恢复原包并保留回滚原因，覆盖后继续保留原 `_local` 数据；备份未能清理时给出真实警告。同一进程中的提交阶段串行执行，解码和暂存仍可并发，避免重复导入交错修改目标包与其私有数据。
- 导出流式读取文件，限制解压后大小；拒绝文件/目录链接，失败时只回收本次独占创建的暂存文件，已有暂存文件不会被覆盖或删除。
- 安全路径检查同时解析现有目标和最近的已存在父目录，修复 Windows 目录链接越界遗漏及原始路径与 canonical 路径前缀不同导致的误拒绝。4 项路径测试包括两个真实、独立的 Windows junction 场景。
- 解开外层目录时只移除一次前缀，保留与外层同名的子目录，避免嵌套资源被展平后相互覆盖。
- 14 项归档测试覆盖真实导出→导入→覆盖、CRC、文件名、大小上限、私有数据、失败、已有暂存文件、目录链接、8 个并发不同包导入、同包重复触发及同名嵌套目录。
- 普通立绘上传复用成功后清理的文件写入逻辑，写入失败不再提前删除旧格式图片；读写和格式清理使用安全路径检查。
- 表情重命名在开始前检查所有格式的目标是否已占用，避免把已有 `new.png` 和旧 `old.jpg` 合并成两个同名表情。
- 校准对损坏的 `layout`/`outfits` 返回明确错误而不 panic；兼容旧配置中的 null 容器，保留其他服装的校准。无效校准参数在访问数据目录前返回错误。
- 9 项立绘行为测试覆盖失败/成功上传、生成导入元数据与覆盖要求、二进制读取、重命名冲突、损坏/旧式校准、完整资源编辑和默认立绘选择。
