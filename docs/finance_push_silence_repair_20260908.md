# 金融主动快讯静默契约修复（2026-09-08）

## 原因

金融插件 0.8.3 的稳定研究提示仍要求模型输出旧文字 sentinel `【不推送】`。
当前 QQ 宿主仅把有效最终 JSON 中明确的空字符串 `speech` 视为主动静默。
云端时间线确认，问题快讯附近多条实际 assistant 正文以旧标签开头且后接说明，
所以普通发送链将其作为正文，再加快讯标题与原文链接发送；并非用户配置的显示标签。

## 修复

- 金融插件 0.8.4 删除旧 sentinel 指令，统一使用宿主现有最终 JSON：`speech: ""`。
  无增量时不输出价值判断、原因或占位说明，也不调用发送工具解释为何不推送。
  历史标签示例不覆盖当前规则，正常用户提问仍正常回答。
- 动态事件说明同步引用现有静默规则；不新增标签解析器、过滤正则、专属发送协议或第二轮模型。
- 宿主生产代码未改。已有规范化器及 QQ 渲染链负责空正文、无标题/链接、无进度文字、无表情。
  本轮补充真实规范化器到 QQ 交付入口的测试，覆盖静默、正常快讯和普通用户解释旧标签。
- 未删除历史消息、未撤回已发快讯、未改订阅、模型配置、财务分析能力或网页读取策略。
  本次不声称解决示例中的网页读取失败。

## 边界

本修复纠正模型收到的静默契约，不把中文标签升级成永久控制协议。
正常用户讨论“【不推送】”时不会被文本过滤器误吞；模型是否认为某条新闻有增量仍由正常研究流程决定。
