# Video 01 Assets

这里放第一期视频《从聊天 Demo 到 AI 陪伴系统》的可视化素材。

- `excalidraw/01_plain_chat_demo.excalidraw`：普通聊天 Demo 的局限
- `excalidraw/02_multi_client_brain.excalidraw`：三端入口共用后端大脑
- `excalidraw/03_turn_pipeline.excalidraw`：一次对话的处理链路
- `excalidraw/04_layered_memory.excalidraw`：三层记忆结构
- `excalidraw_preview.html`：不用打开 Excalidraw 也能先看的静态预览页

使用方式：

1. 打开 Excalidraw。
2. 选择导入文件。
3. 选择对应 `.excalidraw` 文件。
4. 录制时可以一边讲一边拖动、放大、框选重点。

这些图是第一版录制草图，重点是讲清楚项目思路，后面可以继续调颜色、布局和文案。
