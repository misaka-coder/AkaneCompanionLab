3. 一条消息进入系统后，大概经历什么？

  1. 用户发消息
  2. 前端 sendMessage
  3. POST /think
  4. 确认身份和 session
  5. 保存用户消息
  6. 读取可见上下文
  7. 前置记忆检索
  8. 拼接 Prompt
  9. LLM 生成结构化 JSON
  10. 检查 tool_call / 执行工具
  11. NDJSON 流式返回前端
第一期只讲主链路。

目标是让观众知道入口在哪里、数据怎么流、为什么它不是普通聊天框。

RAG / Tool Calling 的细节留到后面单独讲。

4. 长期记忆：不是全塞进 Prompt，而是逐层沉淀

Layer 1：原始对话 raw message细节最多，也最容易变多
压缩 ↓
Layer 2：阶段摘要 episodic summary把一段时间聊过什么压缩下来
再压缩 ↓
Layer 3：长期语义记忆 semantic summary稳定事实 / 长期偏好 / 反复话题 / open loop
