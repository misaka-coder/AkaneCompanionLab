# 插件安装拆分与制品边界验收

## 入口与职责

原 `companion_v01/plugin_installation.py` 的 1,236 行实现已迁到 `plugin_artifact_runtime/`，原文件保留 91 行兼容入口。四个历史类、56 个历史导入绑定、原有方法签名和 `__all__` 继续可用；默认项目根仍指向仓库根目录。

| 模块 | 行数 | 职责 |
|---|---:|---|
| `store.py` | 49 | 单一制品仓库对象、目录配置、共享锁和职责组合 |
| `contracts.py` | 96 | 制品与代次来源契约、限额、结构化错误、权限校验 |
| `storage.py` | 320 | 安装与暂存清单、真实代次来源、严格目录定位、原子文件读写 |
| `staging.py` | 273 | wheel 暂存、源码构建、真实 SDK 源码测试及有界测试输出 |
| `installation.py` | 187 | 显式依赖供应、隔离安装和独立进程准备探针 |
| `dependencies.py` | 164 | wheel 依赖预检、发行包名称规范化、公开安装诊断 |
| `publication.py` | 351 | 精确权限发布、上一可用版本回滚、卸载和可重试清理 |

四个职责 mixin 使用同一个 `ManagedPluginArtifactStore` 的目录、配置和 `RLock`。管理服务、插件市场、候选代次构建仍经原入口访问这个对象，安装记录沿用 schema v2。源码构建继续进入同一 wheel 暂存及探针链；运行时贡献仍由 generation runtime 负责。

## 发布与清理

发布先读取安装记录，再移动已审阅的候选。安装记录写入失败时，新移动的目录恢复为原候选；已存在的相同制品保留到写入成功后才删除重复候选。原可用版本与 last-good 不被失败的发布覆盖。

候选恢复本身失败时返回 `plugin_publication_restore_failed`，保留未提交 release 的 `stage.json` 和内容作为恢复证据；重新暂存相同内容后可复用该目录完成发布。重复候选在发布提交后删除失败时，发布仍反映已提交事实，返回 `stage_cleanup_pending` 与稳定清理原因；管理服务原样传递这些字段，候选仍可通过原 discard 接口清理。

卸载先持久化撤下的版本指针，再按安装记录删除精确 release。运行中任务持有的 site 目录继续保留。删除成功后才撤掉制品记录；删除失败或清理记录写入失败均保留持久证据，下次卸载或对账可以重试。一处删除失败不会阻止其他无引用 release 清理。对账返回独立的清理状态和插件 ID，不把清理失败伪装成 ready，也不要求无关代次重载。

清理只作用于安装记录确认的 `releases/<plugin_id>/<digest>`，并核对目录 digest 与记录键。父目录、其他插件目录、目录别名以及不属于记录的兄弟目录都不会被当成可删除 release。候选目录也核对精确 stage ID，不能通过别名 discard 另一候选。

## 复现与修复

1. 安装记录损坏或写入失败时原来会提前消费候选；现在失败可恢复并重试，保持原可用版本。
2. 相同 digest 的现有 release 缺少 payload 时原来仍可发布；现在保留候选并明确报不可用。发布完成后的重复候选清理失败也有独立结果。
3. 卸载及对账原来在确认删除成功前撤掉记录；现在保留失败、排空中的记录，并允许无版本指针时继续清理。安装记录写入失败不会删除仍被选中的版本。
4. 卸载原来可能递归删除整个插件父目录；现在仅删除有记录的精确 release，错误路径及 digest 别名也不能删除当前或其他插件的文件。
5. 手动及自动回滚原来只检查 last-good 记录是否存在；现在确认该插件的精确目录和 site 可用后才切换。重复回滚如仍等待代次确认，继续报告真实的 pending 状态。
6. 不可用依赖供应源的源码构建原来会留下临时目录；现在先完成配置预检再创建构建目录。
7. 依赖错误和 pip 缺失包诊断原来可能回显带凭据的原始 URL；现在使用结构化错误码、解析后的包名和诊断 ID。正常缺包仍有可用诊断。
8. 主机已提供包的点号、连字符、下划线及大小写别名原来可能被误判成外部依赖；现在统一规范化名称，继续使用原供应链。

新增 `tests/test_plugin_artifact_boundaries.py` 的 28 项检查，含目录边界子用例。用拆分前的安装源码及管理服务源码在内存中执行，25 项复现失败，另外三项保护精确权限拒绝、指针撤下失败和真实持有者释放的既有行为；最终实现全部通过。
