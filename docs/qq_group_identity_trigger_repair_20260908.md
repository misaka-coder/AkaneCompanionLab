# QQ 群身份与文字触发修复 — 2026-09-08

状态：本地实现与回归完成（有一项已确认的既有静态检查失败），未部署。此页替代早期“整体恢复 V6 宿主方法”的草案。

## 当前实现

- 群聊关闭所有文字唤醒；规范化入口明确传空词表。真实 @ 继续按账号 ID 接收，私聊、控制命令、引用跟进和群注意力保持。
- 旧配置 `wake_words` 只兼容已有命令前缀，不再影响消息准入。删除跨 Bot 唤醒词重叠限制；账号和记忆空间隔离校验保留。自检返回 disabled/disabled/[]。
- MemCore V6 渲染器不修改。自身身份仍为 assistant；正文显示正常 `@天为`，结构化提及显示 `天为 (id=assistant)`；删除“助手（本群昵称：…）”包装及其专属解释提示。
- 唯一群显示名来自绑定账号的群成员信息：群名片优先，空白时取该成员 QQ 昵称。返回账号、群范围仍核验；成功缓存 60 秒，失败清掉旧名并回退 15 秒。没有可靠名字时不输出显示名，正文用中性 `@助手`，不信任入站自称标签。
- 当前群身份在共同交付入口、实际执行模型回合前生成，覆盖直接消息、排队任务、群注意力和群插件事件。通过已有 request-scoped extra_context 进入 PromptBuilder，不进入用户正文或冻结聊天投影。私聊不附加该群身份块。
- 群身份只提供群 ID、Bot QQ 账号和一个实际群显示名，不同时输出 QQ 昵称与群名片。没有额外查询群名称，当前会话用真实群 ID 标识。
- 当前显式 @ 优先于引用对象；多个非自身 @ 不指定单一 target。引用事实保留在 reply_to。删除 engine 中“没有 target 就选第一个 mention”的二次推断。

## 模型可见形态

本轮上下文（一次）：

```text
当前会话：QQ群（group:30003）
你的 QQ 账号：qq:10001
你在本群的显示名：天为
```

V6 用户消息：

```text
time: 2026-09-08 周二 10:28
message_id: "1"
actor: 群友 (id=qq:90009)
target: assistant
mentions:
  - 天为 (id=assistant)
text:
  @天为 你怎么看
```

改名后的当前上下文更新，历史 @ 仍保留原先名称。查询缓存允许最长约一分钟刷新延迟，不宣称实时订阅群名片变化。旧错误历史和已入队正文不自动改写。
