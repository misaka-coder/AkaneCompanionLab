# 控制中心应用协调层拆分

入口仍是 `desktop_pet_next/control-center-lab.html` → `src/control-center-v2/index.js`。
页面继续使用现有 bridge、store、view-model 和 components；界面不会直接调用后端。

## 第一片：操作与模型表单

- `app/actions.js` 负责操作锁、操作反馈和反馈过期。操作、计时器和聊天任务反馈分别归属于发起请求。
- `app/model.js` 负责模型表单、提供商切换、模型列表/测试/保存及焦点恢复。
- `app/scope.js` 定义聊天与服务的界面归属，并保留原来的错误说明。

修复旧反馈计时器清除新反馈、旧聊天任务控制结果写入新会话、慢模型请求覆盖新选择或编辑。
会话、bot、角色或实例切换时清理聊天分页状态和操作状态；离开再回到同一会话不会复活先前的请求。
模型输入仍在当前 DOM 上编辑，后台快照不会打断输入法或打开的下拉菜单。

验证：11 项应用行为测试、屏幕观察 smoke、前端构建和真实控制中心入口的浏览器 smoke。
浏览器中的宿主事件和 HTTP 服务使用隔离 fixture；实际 Tauri/WebView2 窗口和真实音频需要另行实机验收。

## 第二片：能力草稿与语音

- `app/capability-payload.js` 保留能力表单及情绪参考样本的校验和请求构造。
- `app/capability-drafts.js` 管理面板展开、表单草稿与编辑/页面/服务归属。
- `app/capabilities.js` 处理插件、审批、工具暴露与能力表单事件。
- `app/voice.js` 处理语音输入草稿、唤醒词、声线编辑/检查和真实试听音频的生命周期。

修复删除的草稿被下一次渲染重新缓存、默认展开状态被覆盖，以及目录选择或声线检查覆盖较新的编辑。
角色/实例/bot 切换会清理对应草稿与声线建议，停止先前的试听。关闭窗口与播放失败均释放音频 URL。
应用行为测试增至 21 项；7 页真实入口浏览器 smoke 和构建通过。

## 第三片：聊天、渲染与生命周期

入口从 1,277 行缩为 38 行，只组装依赖、订阅状态并处理卸载。应用实现共 13 个模块，最大 177 行。

| 模块 | 责任 | 行数 |
| --- | --- | ---: |
| `app/actions.js` | 操作锁、归属检查、反馈与过期清理 | 104 |
| `app/model.js` | 模型表单、提供商与请求结果 | 117 |
| `app/scope.js` | 归属键与错误说明 | 20 |
| `app/capability-payload.js` | 能力表单及情绪样本校验 | 172 |
| `app/capability-drafts.js` | 草稿、展开状态与编辑版本 | 76 |
| `app/capabilities.js` | 插件、审批、能力表单与工具暴露交互 | 93 |
| `app/voice.js` | 唤醒词、声线编辑与试听生命周期 | 151 |
| `app/chat.js` | 发送草稿、附件事件、分页与滚动锚点 | 177 |
| `app/presentation.js` | 设备外观偏好、取景拖动与主题监听 | 130 |
| `app/render-policy.js` | 表单焦点保护与页面渲染依赖 | 32 |
| `app/render.js` | 组件渲染、页面滚动、焦点与草稿恢复 | 46 |
| `app/snapshot.js` | 快照同步、启动、刷新与关闭 | 67 |
| `app/events.js` | DOM 事件委托与旧页面参数兼容 | 72 |

聊天发送回执只清空当时提交的草稿；后续输入和新会话不会被旧结果清空或抢走焦点。
分页的加载反馈、滚动锚点和重试归属于会话、bot、角色与实例。过期分页结果不会让当前加载状态卡住。
聚焦表单仍延迟普通快照；切换会话或对象必须立即替换旧控件。延期渲染使用当前 store，避免回放旧页面状态。
模型页的渲染依赖补齐独立视觉服务与清除密钥开关。取景拖动结束或取消时才刷新等待的渲染，普通导航不提前刷新 DOM。
刷新请求单独去重；过程中收到的实时快照不会解除刷新锁，返回的旧快照也不会覆盖较新的发布。
卸载统一移除事件、订阅、主题监听和计时器，停止试听、图片预览与 bridge，并隔离未完成请求的回调。

原能力表单/情绪样本校验、错误说明和按钮值转换保留；对照拆分前源码确认 25 个操作 ID 字面量均未丢失。
模型配置仍通过已有 admin bridge，缓存和版本检查只保存在窗口内存中。

## 最终验证

- 35 项应用行为测试、26 项 view-model 行为测试；模块检查确认 13 个应用模块可达、无循环依赖、无未绑定标识符。
- `npm run verify:control-center`：数据源、91 项生产操作、V2、runtime probe、build 与 UX 结构检查通过。
- 43 项 Python 前端/气泡合同检查，以及屏幕观察 smoke 通过。
- Edge 浏览器加载真实 `control-center-lab.html`、bridge、store 和 DOM：7 页导航、聚焦编辑/选区、独立视觉开关、发送与新草稿竞态、聚焦时延迟切换会话、音量空值/零值、旧确认、失败/重试、离线重连和重新进入均通过，页面错误为 0。
- 浏览器截图检查覆盖模型、聊天和语音。旧 UX 工具的 Puppeteer 截图步骤因缺少 Puppeteer 跳过；上述 Edge smoke 单独生成截图并检查。
- `git diff --check` 通过。未触碰已有后端改动；实际 Tauri/WebView2、麦克风、声卡及外部 TTS 服务仍需实机验收。
