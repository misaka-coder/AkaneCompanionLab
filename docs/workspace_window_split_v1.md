# 工作区窗口拆分

生产入口保持 `workspace.html` → `src/workspace.js`。入口从 1065 行缩为 6 行，只组装宿主与工作区应用。
`src/workspace/` 有 9 个模块，最大 189 行；入口与实现合计 1155 行。增加的 90 行主要用于请求归属、重复操作防护和关闭清理。

## 定位入口

| 模块 | 责任 | 行数 |
| --- | --- | ---: |
| `application.js` | 状态初始化、范围版本、文件刷新、防抖与窗口生命周期 | 189 |
| `host.js` | Tauri、实时事件、启动绑定、聊天授权传输、剪贴板及关闭 | 52 |
| `transport.js` | 捕获请求目标、实例验证、工作区读写与原生文件参数 | 116 |
| `events.js` | DOM 委托、快捷键、实时订阅与 disposer | 71 |
| `projects.js` | 项目列表、创建/选择/归档/目录选择与项目操作锁 | 177 |
| `files.js` | 打开、定位、复制、导出、播放、收起与清理 | 108 |
| `items.js` | 文件/成果卡片、统计、按钮可用性与卡片查找 | 186 |
| `music.js` | 音乐状态、歌词、队列和控制按钮的显示 | 143 |
| `view.js` | DOM 选择、状态反馈、更新时间与共用显示格式 | 107 |

文件显示问题先看 `items.js`，文件操作问题先看 `files.js` 和 `transport.js`；项目问题看 `projects.js`，音乐显示看 `music.js`，切换或关闭问题看 `application.js` 和 `events.js`。
模块检查沿生产入口遍历，验证实现可达、没有循环依赖和未绑定标识符。原生依赖与全局平台访问集中在 `host.js`。

## 行为修复

- 窗口请求捕获 host/实例、后端、bot、用户、会话和角色包。切换立即取消旧 HTTP 请求、清空旧卡片，并允许新范围刷新；迟到的成功、空结果和失败都不能发布。
- A→B→A 也推进范围版本，避免同名会话或同一角色回来后恢复最初的旧请求。较新的实时快照优先于慢持久状态读取。
- 同一范围刷新保留一次尾部请求；设置读取失败时，已经排队的重试仍会执行。初始化失败保留原因，并阻止未准备好的后端操作。
- 项目列表独立读取，慢项目请求不阻挡文件托盘。旧列表不能覆盖新列表；创建结果只清除自己提交的草稿，操作锁防止重复提交。
- 打开、定位和导出要求原生返回真实 `ok`；后端 HTTP 200 中的拒绝也保留错误原因。旧路径返回后不能写入新会话的剪贴板。
- 文件操作进行时禁用操作按钮；重复清理只确认、提交一次。旧操作不能释放新操作锁，也不能刷新或覆盖新范围的反馈。
- 文件和成果卡片的查找键包含所属分区，同编号卡片仍能分别操作；显示空态时清除旧卡片引用。
- 音乐队列索引 0 正确显示第 1 首的序号。音乐操作发送失败保留原因，关闭或切换后迟到的目标发送失败不会再全局重发。
- 关闭释放 DOM/native 监听和计时器，取消 HTTP 请求；迟到的监听注册立即释放。重新打开窗口创建新的应用实例。

后端接口和 Rust 命令参数保持既有契约。工作区摘要仍按 bot、用户和会话读取；角色包用于前端请求归属与工作区写操作，并未新增后端摘要按角色过滤的能力。
目录选择与宿主路径处理继续由原生层负责；项目命令仍使用原生层当时的持久绑定。已提交的原生文件操作或目录选择不能由前端 HTTP abort 撤回，前端负责隔离迟到结果和后续动作。
聊天凭据继续由既有 `createDesktopConversationFetch` 获取；没有新增密钥存储或原生路径快照。

## 验证

- `npm run test:workspace`：38 项行为测试，覆盖失败、空态、慢请求、重复触发、范围切换、草稿与反馈归属、部分订阅失败和关闭。
- `npm run smoke:workspace-modules`：9 个生产模块全部可达，无循环、无未绑定标识符，宿主边界通过。
- `npm run smoke:workspace-import`：继续直接验证真实 Rust 命令所需的 camelCase 参数，同时覆盖主桌宠导入队列、范围取消和部分失败。
- `node scripts/desktop-conversation-auth-smoke.mjs`：既有聊天授权、凭据失效恢复与取消检查通过。
- 44 项 Python 前端、气泡和实例隔离契约检查通过；工作区源码检查沿入口追踪实际模块。
- `npm run smoke:workspace-browser`：Edge 加载真实入口和 DOM；文件/成果分区、音乐/歌词/队列、项目创建与取消、原生拒绝、失败/空态/重试、慢会话和角色切换、重复清理、关闭与重新进入通过，页面错误为 0。
- `npm run build` 与 `git diff --check` 通过。拆分前后 AST 对照确认 25 个保留函数体一致。

浏览器使用隔离 HTTP/native fixture，截图在忽略目录 `.codex/workspace-browser-smoke/`。
真实 WebView2、原生目录选择、系统打开/导出和声卡播放仍需实机验收；本轮没有启动这些服务或改动后端。
