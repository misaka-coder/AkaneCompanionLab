# 剖视图画法直观说明

## 适用对象

这份说明用于讲解一类机械制图题：已给出零件的主视图和侧视图，需要根据中间剖切位置画出剖视图。

图片中的零件可以理解为一个带有圆孔、长圆槽、凸台和安装孔的板状零件。画剖视图时，不要一开始就纠结全部尺寸，先判断剖切面从哪里经过、哪些地方是实体、哪些地方是孔或槽。

## 一句话理解
剖视图就是：

> 想象用一把刀沿指定位置把零件切开，拿走靠近观察者的一半，再看剩下那一半的内部结构。

画图时遵循：

- 切到实体材料的地方，画剖面线。
- 切到孔、槽、空腔的地方，保持空白。
- 原来用虚线表示的内部轮廓，剖开后通常改画成粗实线。
- 中心线仍然保留，用细点画线表示。

## 本题应该怎么剖

从图形特征看，这个零件左右对称，主视图中间有一条竖直中心线。常规画法是沿这条竖直中心线作全剖视图。

剖切面经过：

- 上方圆孔中心。
- 中间长圆槽中心。
- 下方大圆孔中心。
- 零件中间的主要实体部分。

可以把它想成这样：

```text
主视图示意

        A
        ↓
    ┌────────┐
    │   ○    │
    │   │    │
    │   │    │
    │   ○    │
    └────────┘
        ↑
        A

A-A 剖切面沿竖直中心线通过孔和槽。
```

## 画图步骤

### 1. 先确定剖切线

在主视图上沿竖直对称中心线布置剖切线，标注为 A-A。

如果题目没有特别要求阶梯剖，通常不要为了经过所有螺钉孔而把剖切线弯来弯去。普通全剖主要表达中间孔、槽和主体内部结构。

### 2. 先画外轮廓

以侧视方向为基础，先画出零件的外形轮廓。

这一步可以先照着原来的侧视图画：

- 左侧板厚。
- 右侧凸出的主体。
- 上下台阶。
- 右侧小凸台。
- 总长度和局部厚度关系。

先不要急着画剖面线。

### 3. 把内部轮廓改成剖开后的实线

普通侧视图中，内部孔、槽可能用虚线表示。剖开以后，这些内部结构暴露出来，应改为可见轮廓线。

也就是说：

```text
普通视图中：

外形线：粗实线
内部不可见结构：虚线

剖视图中：

被剖开后看得见的内部边界：粗实线
孔、槽内部：空白
```

### 4. 画剖面线

判断哪些区域是被切到的实体材料。

实体材料区域画 45 度细实线剖面线：

```text
实体材料：

┌//////////┐
│//////////│
│//////////│
└//////////┘
```

孔、槽、空腔不要画剖面线：

```text
被剖到的孔：

┌//////////┐
│////  ////│
│////  ////│
└//////////┘

中间空白表示孔或槽。
```

同一个零件的剖面线方向和间距要一致。

### 5. 删除不必要的虚线

剖视图已经把内部结构表达出来了，所以一般不再保留大量虚线。

保留：

- 中心线。
- 必要的对称轴线。
- 少量确实有表达意义的不可见轮廓。

删除：

- 已经被剖开、可以直接看见的内部虚线。
- 会让图面混乱的重复虚线。

## 给同学讲的直观比喻

可以这样讲：

> 这个题不要先背画法，先想象切蛋糕。刀从中间竖着切下去，切到蛋糕的地方画斜线，切到洞的地方就空着。然后从右边看这个切开的面，看到的就是剖视图。

更简化一点：

```text
第一步：一刀切开

    ┌────────┐
    │   ○    │
    │   │    │
    │   ○    │
    └────────┘
        │
        │ 剖切面
        │

第二步：拿走前半边

    剩下后半个零件

第三步：看切口

    实体部分：画 ///////
    孔和槽：留白
```

## 常见错误

### 错误 1：孔里面也画剖面线

孔、槽、空腔不是实体材料，不能画剖面线。

### 错误 2：剖开后还保留一堆虚线

剖视图的目的就是减少虚线，让内部结构变清楚。已经剖开的内部轮廓应该改成实线。

### 错误 3：剖面线方向乱变

同一个零件的剖面线方向和间距应一致。不要一块区域向左斜，另一块区域向右斜。

### 错误 4：没有保留中心线

圆孔、圆柱、对称结构仍然需要中心线。剖视图不是把所有辅助线都删掉。

### 错误 5：把所有小孔都强行剖开

如果题目没有要求阶梯剖，不需要为了经过每个螺钉孔而改变剖切路线。普通全剖通常沿对称中心线剖。

## 检查清单

画完后按这几个问题检查：

- 剖切面位置是否沿主视图中心线？
- 外轮廓是否和侧视图对应？
- 被剖到的实体是否都有剖面线？
- 孔、槽、空腔是否留白？
- 内部虚线是否改成必要的实线？
- 中心线是否保留？
- 同一零件的剖面线方向和间距是否一致？

## 最后记忆口诀

```text
一看剖哪儿，
二画外轮廓，
三把虚线变实线，
四给实体打斜线，
五让孔槽留空白。
```
