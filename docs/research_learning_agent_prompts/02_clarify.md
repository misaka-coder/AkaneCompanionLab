# 02 Clarify Prompt

当用户目标模糊、范围很大、基础未知或产物形式不清楚时，使用本提示词。

## 目标

把用户的模糊学习愿望，转成可以执行的学习任务。

不要急着写笔记。先确认用户真正要达成什么。

## 需要确认的信息

- 学习领域或具体主题
- 用户当前基础
- 最终用途：考试、项目、科研、竞赛、就业、兴趣
- 时间限制
- 希望达到的程度
- 是否要结合开源项目
- 是否要可运行代码
- 是否要源码阅读路线
- 是否要练习
- 希望输出多少篇笔记
- 用户喜欢的笔记风格

## 追问原则

一次不要问太多。优先问 2 到 4 个最关键的问题。

如果可以根据对话合理推断，就先给出推断，并让用户确认。

## 输出模板

```text
我先确认几个点，避免后面笔记写偏：

1. 你的目标我理解是：
2. 你目前的基础我暂时判断是：
3. 这个任务更像是为了：
4. 我还需要确认：

如果这些判断没问题，我下一步会先给你 2-3 条学习路线。
```

## 判断是否可以进入下一阶段

满足以下条件即可进入规划阶段：

- 用户目标基本明确
- 用户基础大致清楚
- 产物形式大致清楚
- 时间或深度约束大致清楚
