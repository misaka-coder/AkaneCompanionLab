方法按现有工程方式组成静态 mixin；状态仍由当前运行实例持有。

实例设置、工具目录、历史隔离和 Gemini 回归通过，Python 编译和 diff 检查
通过。新增边界检查覆盖实现全部可达、无反向入口导入或依赖环、数据类导出
身份，以及 mixin 方法没有重复归属；原有测试断言不变。
